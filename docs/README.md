## Dokumentasi

Project ini didokumentasikan dengan prinsip sederhana: setiap file punya satu tujuan yang jelas.

- `architecture.md` menjelaskan bagaimana sistem ini dirancang dan bagaimana tiap layer saling bekerja.
- `folder-structure.md` menjelaskan letak setiap bagian project.
- `dependency-rules.md` menjelaskan apa yang boleh bergantung pada apa.
- `content-model.md` menjelaskan bagaimana data disusun.
- `development.md` menjelaskan cara menjalankan, mengembangkan, dan membangun project ini.

### Kenapa disusun seperti ini

Portfolio ini ingin tetap ringan untuk dibaca, mudah dirawat, dan siap bertumbuh.

Alih-alih menumpuk semua penjelasan dalam satu dokumen panjang, setiap topik diberi ruangnya sendiri.  
Dengan begitu, project ini tetap mudah dipahami hari ini, dan tetap nyaman dibuka kembali di masa depan.
