## About

This repository contains the source code of my personal portfolio.

More than a collection of projects and certificates, this portfolio is a reflection of my journey into software engineering — from exploring different areas of technology to gradually understanding how software systems are designed, built, deployed, and maintained.

I started exploring software engineering in 2025, moving across frontend, backend, databases, security, CI/CD, DevOps, and product engineering.

Today, I'm particularly interested in going deeper into:

- Backend Engineering
- System Design
- DevOps & Infrastructure
- Software Architecture
- Product Engineering

I'm still exploring, still learning, and still building.
